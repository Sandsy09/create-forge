# CF-25.02 — Extract command orchestration behind a thin Typer layer

**Repository:** `create-forge`  
**Priority:** P2  
**Planning baseline:** 21 September 2026

## Outcome

Extract command orchestration behind a thin Typer layer with the acceptance evidence below.

## Issue context

This work comes from the 21 September 2026 engineering review. Live reconciliation on 21 September confirms forge-template 0.6.0 is published, create-forge PR #186 is merged and CF-21.01 is closed; CF-21.02 and CF-21.03 remain open. Review observations must be rechecked against the implementation candidate.

`create-forge` owns CLI UX, ProjectSpec construction, source isolation, destination filesystem/Git/hooks and error presentation. `forge-template` owns descriptors, manifests, composition, generated content, provenance and in-memory update planning. Data flow: create-forge → ProjectSpec → forge-template discovery/render/plan → create-forge filesystem/Git finalisation.

## Problem statement

Command registration and orchestration are concentrated in cli.py, increasing coupling and review cost.

## Proposed resolution

Move command-specific orchestration into focused internal modules using the accepted seams; leave Typer registration and dependency direction clear.

## Scope

Implement the stated resolution and acceptance criteria in this repository; update affected living contracts in the same PR.

## Acceptance criteria

- [ ] Extract in small reviewable changes for new/list/update/doctor with no changes to public options, defaults, output contracts or exit codes.
- [ ] Keep staging, filesystem effects, Git/hooks and ProjectSpec construction in the client; provider imports remain at approved seams.
- [ ] Preserve both installed and isolated engine paths, optional legacy imports and path/decoding safeguards.
- [ ] Run the characterisation and affected installed suites after each slice; no line-count target substitutes for coherent responsibilities.

## Exclusions

No new UX features, shared framework or provider-specific orchestration.
