## Problem statement

## Proposed resolution

Run installed safety regressions on the combined candidate, record immutable commits and provider artefacts, and make the evidence an explicit CF-21.03 release prerequisite.

## Scope

- [ ] Record the scope and outcome of all required tests; if safety-relevant candidate code changes, refresh affected evidence before publication.
- [ ] CF-21.03 has the safety evidence and CF-21.02 installed Streamlit evidence before release; do not block a narrowly scoped emergency safety patch on unrelated feature completion.
