## Problem statement

An approved budget needs executable enumeration, coverage and timing checks to detect regression.

## Proposed resolution

Implement the accepted tiers and reporting, with deterministic selection, full release/scheduled sweeps and explicit PR escalation.

## Scope

Implement the stated resolution and acceptance criteria in this repository; update affected living contracts in the same PR.

## Acceptance criteria

- [ ] Publish matrix-size and timing reports, including expected versus executed cases and evidence of zero silent omissions.
- [ ] Exercise fast PR, affected-surface escalation, scheduled exhaustive and release-exhaustive execution paths.
- [ ] Fail the agreed regression threshold with actionable attribution; transient infrastructure failures are distinguishable from test failures.
- [ ] Releases cannot bypass the exhaustive tier or the required independent-client evidence.
- [ ] Show baseline comparison and run instructions; update CONTRIBUTING and aggregate CI gates without weakening required safety checks.

## Exclusions
